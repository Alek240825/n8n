# Ejercicios del Módulo 3: Excel

## Ejercicio 3.1: Lectura de Excel
- Leer un archivo Excel
- Filtrar filas específicas
- Transformar datos

## Ejercicio 3.2: Manipulación de Datos
- Agregar nuevas columnas
- Aplicar fórmulas
- Ordenar y filtrar datos

## Ejercicio 3.3: Exportación
- Crear un nuevo archivo Excel
- Formatear celdas
- Agregar múltiples hojas

## Desafío Final
Crear un sistema que:
1. Lea múltiples archivos Excel
2. Consolide la información
3. Aplique transformaciones
4. Genere un reporte final
