# Ejercicios del Módulo 16: Integración de Mensajería

## Ejercicio 16.1: Bot de Atención Básico
Crear un bot de WhatsApp que:
- Reciba mensajes vía webhook
- Identifique palabras clave básicas
- Responda con mensajes predefinidos
- Registre las conversaciones en una hoja de cálculo

## Ejercicio 16.2: Sistema de Notificaciones
Implementar un sistema que:
- Envíe notificaciones por SMS y WhatsApp
- Permita programar envíos
- Use plantillas personalizadas
- Maneje confirmaciones de entrega

## Ejercicio 16.3: Menú Interactivo
Desarrollar un menú interactivo que:
- Muestre opciones con botones
- Procese las respuestas del usuario
- Derive a diferentes flujos según la selección
- Mantenga un registro de las interacciones

## Ejercicio 16.4: Verificación en Dos Pasos
Crear un sistema de verificación que:
- Genere códigos únicos
- Envíe códigos por SMS
- Valide las respuestas
- Maneje reintentos y expiración

## Desafío Final
Implementar un sistema completo que:
1. Combine WhatsApp y SMS
2. Use mensajes interactivos
3. Integre con base de datos
4. Maneje errores y reintentos
5. Genere reportes de uso
