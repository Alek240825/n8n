# Ejercicios del Módulo 2: Tu Primer Workflow

## Ejercicio 2.1: Automatización Simple
- Crear un workflow con trigger manual
- Procesar datos de entrada
- Generar una salida formateada

## Ejercicio 2.2: Nodos Básicos
- Usar Set
- Implementar Function
- Combinar múltiples nodos

## Ejercicio 2.3: Depuración
- Usar nodos Debug
- Identificar errores comunes
- Implementar logs básicos

## Desafío Final
Crear un workflow completo que:
1. Acepte datos de entrada
2. Realice validaciones
3. Transforme la información
4. Genere un reporte
