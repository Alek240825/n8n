# Ejercicios del Módulo 8: Proveedores de IA

## Ejercicio 8.1: OpenAI
- Conectar con API de OpenAI
- Generar texto con GPT
- Implementar chat interactivo

## Ejercicio 8.2: Azure AI
- Configurar servicios de Azure
- Usar Cognitive Services
- Implementar análisis de texto

## Ejercicio 8.3: Integración Multi-proveedor
- Combinar diferentes APIs
- Comparar resultados
- Implementar fallbacks

## Desafío Final
Desarrollar un sistema que:
1. Use múltiples proveedores de IA
2. Implemente failover
3. Compare resultados
4. Optimice costos
