# Ejercicios del Módulo 1: Fundamentos

## Ejercicio 1.1: Mi Primer Workflow
- Crear un workflow que muestre "Hola Mundo"
- Usar el nodo Schedule para ejecutarlo cada minuto
- Agregar un nodo Function para modificar el mensaje

## Ejercicio 1.2: Variables y Datos
- Crear variables con diferentes tipos de datos
- Manipular strings y números
- Usar expresiones y operadores

## Ejercicio 1.3: Control de Flujo
- Implementar condiciones IF
- Usar switches para múltiples casos
- Manejar errores básicos

## Desafío Final
Crear un workflow que:
1. Se ejecute cada hora
2. Genere datos aleatorios
3. Aplique transformaciones
4. Muestre resultados formateados
