# Ejercicios del Módulo 9: IA con Texto

## Ejercicio 9.1: Análisis de Sentimiento
- Procesar comentarios
- Clasificar sentimientos
- Generar reportes

## Ejercicio 9.2: Generación de Texto
- Crear resúmenes automáticos
- Generar variaciones de texto
- Traducir contenido

## Ejercicio 9.3: Chatbot Inteligente
- Implementar diálogo natural
- Manejar contexto
- Responder preguntas

## Desafío Final
Crear un sistema que:
1. Analice texto en tiempo real
2. Genere respuestas contextuales
3. Aprenda de interacciones
4. Produzca reportes analíticos
