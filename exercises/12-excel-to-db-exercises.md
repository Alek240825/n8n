# Ejercicios del Módulo 12: Excel a Base de Datos

## Ejercicio 12.1: Importación Automática
- Leer Excel automáticamente
- Mapear columnas
- Validar datos

## Ejercicio 12.2: Transformación de Datos
- Limpiar datos
- Convertir tipos
- Manejar valores nulos

## Ejercicio 12.3: Sincronización
- Detectar cambios
- Actualizar registros
- Mantener histórico

## Desafío Final
Desarrollar un sistema que:
1. Importe múltiples Excel
2. Valide la integridad
3. Sincronice con BD
4. Genere reportes de errores
