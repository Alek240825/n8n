# Ejercicios del Módulo 5: Imágenes

## Ejercicio 5.1: Procesamiento Básico
- Redimensionar imágenes
- Convertir formatos
- Ajustar calidad

## Ejercicio 5.2: Manipulación Avanzada
- Aplicar filtros
- Agregar marcas de agua
- Recortar automáticamente

## Ejercicio 5.3: Batch Processing
- Procesar múltiples imágenes
- Organizar por carpetas
- Generar miniaturas

## Desafío Final
Crear un sistema de procesamiento que:
1. Procese imágenes en lote
2. Aplique transformaciones personalizadas
3. Organice los resultados
4. Genere un reporte de cambios
