# Ejercicios del Módulo 6: MySQL

## Ejercicio 6.1: Operaciones CRUD
- Insertar registros
- Leer datos con filtros
- Actualizar registros existentes
- Eliminar datos específicos

## Ejercicio 6.2: Consultas Complejas
- Usar JOIN entre tablas
- Implementar subconsultas
- Aplicar agregaciones

## Ejercicio 6.3: Gestión de Datos
- Importar datos masivos
- Validar información
- Manejar duplicados

## Desafío Final
Desarrollar un sistema que:
1. Sincronice datos entre tablas
2. Implemente validaciones
3. Maneje errores
4. Genere logs de operaciones
