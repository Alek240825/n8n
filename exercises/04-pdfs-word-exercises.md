# Ejercicios del Módulo 4: PDFs y Word

## Ejercicio 4.1: Manipulación de PDFs
- Convertir PDF a texto
- Extraer páginas específicas
- Combinar múltiples PDFs

## Ejercicio 4.2: Documentos Word
- Crear plantillas
- Rellenar datos automáticamente
- Exportar a diferentes formatos

## Ejercicio 4.3: Automatización de Documentos
- Procesar documentos en lote
- Extraer datos estructurados
- Generar reportes automáticos

## Desafío Final
Implementar un sistema que:
1. Lea documentos PDF y Word
2. Extraiga información clave
3. Genere nuevos documentos
4. Archive los resultados
