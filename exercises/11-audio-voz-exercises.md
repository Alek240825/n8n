# Ejercicios del Módulo 11: Audio y Voz

## Ejercicio 11.1: Text-to-Speech
- Convertir texto a voz
- Personalizar voces
- Generar audiolibros

## Ejercicio 11.2: Speech-to-Text
- Transcribir audio
- Detectar idiomas
- Extraer palabras clave

## Ejercicio 11.3: Procesamiento de Audio
- Limpiar ruido
- Ajustar velocidad
- Combinar pistas

## Desafío Final
Crear un sistema completo que:
1. Procese archivos de audio
2. Genere transcripciones
3. Cree síntesis de voz
4. Archive resultados
