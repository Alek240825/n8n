# Ejercicios del Módulo 10: IA con Imágenes

## Ejercicio 10.1: Generación de Imágenes
- Usar DALL-E
- Generar variaciones
- Modificar imágenes existentes

## Ejercicio 10.2: Análisis Visual
- Detectar objetos
- Reconocer texto
- Analizar escenas

## Ejercicio 10.3: Procesamiento Avanzado
- Combinar generación y análisis
- Implementar edición inteligente
- Crear colecciones temáticas

## Desafío Final
Implementar un sistema que:
1. Genere imágenes personalizadas
2. Analice contenido visual
3. Aplique mejoras automáticas
4. Archive y categorice resultados
