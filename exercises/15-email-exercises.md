# Ejercicios del Módulo 15: Integración de Email

## Ejercicio 15.1: Gmail Básico
- Configurar conexión Gmail
- Enviar emails simples
- Leer bandeja de entrada

## Ejercicio 15.2: Outlook Avanzado
- Configurar Outlook
- Usar plantillas HTML
- Manejar adjuntos

## Ejercicio 15.3: Automatización de Email
- Procesar emails entrantes
- Responder automáticamente
- Clasificar mensajes

## Ejercicio 15.4: Sistema de Notificaciones
- Crear plantillas
- Programar envíos
- Monitorear entregas

## Desafío Final
Crear un sistema completo que:
1. Integre múltiples proveedores
2. Procese emails automáticamente
3. Maneje adjuntos
4. Genere reportes de actividad
